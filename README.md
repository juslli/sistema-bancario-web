# 🏦 Sistema Bancário Web

Painel visual de um sistema bancário desenvolvido com HTML, CSS e JavaScript puro.

## 🔗 Acesse o projeto
👉 [Clique aqui para acessar](https://juslli.github.io/sistema-bancario-web)

## 📋 Funcionalidades

- ✅ Criar conta bancária
- ✅ Depositar dinheiro
- ✅ Sacar dinheiro (com validação de saldo)
- ✅ Ver extrato
- ✅ Listar todas as contas

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
